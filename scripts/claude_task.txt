撰写代码实现计划，所有代码要实现在 scripts/news_monitor 中，实现一个后台一直运行的新闻抓取和分析，以及邮件发送功能脚本。要求包含如下功能。
（1）设置要监控的关键词。例如 “伊朗，中东，原油，黄金”。关键词写在 @.env 文件中。以列表形式存储。

（2）设置抓取目标为 “ 新浪财经-全球财经快讯” ，使用 akshare 的函数 ak.stock_info_global_sina() （位于 @scripts/akshare/akshare/stock_feature/stock_info.py）。
akshare的文件夹路径在 scripts/akshare。如果有调用需求你可以自己创建 __init__.py 文件，以及其他的调用需要的配置。需要列在计划中。

（3）设置存储目标为 mongodb。单独存储一个数据库 stock_news
ak.stock_info_global_sina() 能够获取的信息包含下面的内容：
时间：发布时间（精确到分钟,所有时间都使用 UTC+8 时区）
内容：新闻正文
要求每条新闻都有一个用于存储和查询的 id key。id 通过时间生成，数据来源已经确保不同的新闻不会有重复的时间。id中需要带有"sina"，为了与以后其他形式的来源区分开。
把这些内容存储到数据库的表中：包含时间，内容，以及该新闻是否已经邮件发送过。

异常处理：如果正文为空，则不存储该新闻。

（4）实现通过 id 进行新闻基础信息和正文内容的获取，分别写一个接口。
实现通过 title 搜素新闻是否在 mongo 数据库内已经存储的接口。
所有抓取到的新的新闻，都要存储到 mongo 数据库中。

（5）实现对数据库中存储的新闻正文的关键字搜索功能，例如 search_stock_news(keyword, start_time, end_time) 函数
start_time 和 end_time 都以 yyyy-mm-dd-hh-mm-ss 形式传入。
keyword 是关键词字符串。
执行关键词搜索后，返回所有包含关键词的新闻id列表。

（6）运行此 python 程序后，在运行开始时，以及后续每 10 分钟抓取一次新闻数据，并检查这些新闻 url id 是否已存在于 mongo 数据库中。
如果不存在的话，那么就存储到 mongo 数据库中。

（7）在每 10分钟抓取完新闻数据并存储后，检查 （1）中设置的关键词，进行全数据库搜索，然后在获取到的内容中，查找尚未邮件发送的新闻。
如果存在未通过邮件发送的新闻，则进行发送。

（8）组织邮件发送内容：
标题：[关键词(如果有多个关键词则用'-'连接)]-[本次新闻抓取的时间（精确到分钟）] 
邮件正文：
新闻时间 \r\n 新闻正文 \r\n。逐项排列

（9）发送邮件到 @.env EMAIL 指定的邮箱。发送邮件的函数可以参考 @scripts/mail/stockmail_central.py.py
如果能生成公用函数，可以提取到一个新建文件 @scripts/mail/mail_utils.py 中。

（10）实现启动脚本 start_news_monitor.sh ，启动监控的 python 程序。
参考 @scripts/mail/start_mail_monitor.sh 以及它调用的 python 程序，注意处理 sh 脚本 ctrl+c 退出时清理干净资源占用。

要求每一步操作都有可查询的 print 日志输出，以及对各种请求失败的情况，也要有 print 日志输出。
